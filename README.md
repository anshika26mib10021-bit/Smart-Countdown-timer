Project Title
Smart Countdown Timer using Python Tkinter

Description
This project is a graphical countdown timer made with Python and Tkinter. The application accepts minutes and seconds from the user and provides Start, Pause/Resume, Reset and Stop controls.
It also displays the current timer status, stores timer activity in a history list, allows the history to be cleared, and gives an alarm when the countdown reaches zero.

Features
Start countdown
Pause and resume countdown
Reset timer
Stop timer
Timer status display
Timer history
Clear history
Input validation
Completion message
Windows alarm using winsound with a Tkinter bell fallback

Main Learning Concepts
Classes and objects
Functions/methods
Variables
Conditional statements
Exception handling
Tkinter GUI widgets
after() and after_cancel()
Listbox history
Basic event-driven programming

Technologies Used
Python 3
Tkinter
time
winsound on Windows
